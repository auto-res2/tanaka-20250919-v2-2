The core methodology is an iterative LLM-driven objective discovery pipeline. An LLM (GPT-4) is prompted to propose and implement new preference optimization loss functions in PyTorch code. These proposed functions are then evaluated by finetuning an LLM model and measuring its performance on a downstream validation task (MT-Bench scores). The performance metric is fed back to the LLM as in-context examples, enabling iterative refinement and exploration of the loss function search space. This process identifies high-performing functions, with DiscoPOP (Log Ratio Modulated Loss, LRML) being a dynamically weighted sum of logistic and exponential losses, where the weight is determined by a sigmoid function of the log-ratio difference (ρ).
